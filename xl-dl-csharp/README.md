# 迅雷下载 C# / Unity SDK 指南

XL Download C# SDK 面向 C# 应用开发者，覆盖 .NET 桌面应用和 Unity 项目。选择与你的应用类型匹配的文档开始接入：

## 接入入口

- [.NET Desktop](https://github.com/xunlei-open/xunlei-dlsdk/tree/main/xl-dl-csharp/dotnet)：适用于 Windows、macOS、Linux，使用 NuGet 安装。
- [Unity](https://github.com/xunlei-open/xunlei-dlsdk/tree/main/xl-dl-csharp/unity)：适用于 Unity 的 Windows、macOS、Android arm64-v8a、iOS 项目，使用 GitHub UPM URL 安装。

## 支持平台

| SDK | Windows x64 | Windows x86 | macOS Universal | Linux x64 | Android arm64-v8a | iOS |
| --- | --- | --- | --- | --- | --- | --- |
| .NET Desktop | ✅ | ✅ | ✅ | ✅ | ❌ | ❌ |
| Unity | ✅ | ❌ | ✅ | ❌ | ✅ | ✅ |
