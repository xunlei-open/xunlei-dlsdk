# 迅雷下载 SDK

**官网**：<https://open.xunlei.com>

20 年技术沉淀，提供稳定、低成本、高速下载服务。

## 特性

- **速度快** — 领先业界 P2SP 技术，大幅提升下载速度，解决大文件、高并发场景下带宽瓶颈问题。
- **低成本** — 相对传统 CDN 价格降低 70%，极大降低带宽成本。
- **超稳定** — 专注下载领域 20 年，强大的技术团队为业务 24 小时保驾护航。
- **接入简单** — 精简实现的 SDK 库，支持 Windows、macOS、iOS、Android、Linux，注册应用获取密钥即可快速接入。

## 快速开始

1. 前往[接入流程](https://open.xunlei.com/doc?doc=access_flow)注册并获取 `APP ID` 和 `API Key`。
2. 按编程语言选择下方对应目录，查看 README 安装 SDK。
3. 参考 `examples/` 下的完整示例验证接入。
